# 编剧 Skill（Screenwriter）

> 一个帮你从文学名著里挑剧情、直接产出 1-2 分钟短视频方案的 Claude/DSH 技能。

给想做短视频、但脑子里"没有剧情"的人：你只需要说出想要的感觉，它从 **125 部名著与史部典籍**（中国文学 70 + 中国史部 25 + 西方 30，全部公有领域）里帮你匹配剧情，并生成剧情线、分镜表、旁白文案、标题——你用自己的照片和自己的声音，就能做出 1-2 分钟视频。

## 它解决什么问题

想做一条 1-2 分钟的视频，但不想自己编故事，也不知道从哪里找题材。这个 skill 把「古今中外名著 + 中国史部典籍」变成一张张可检索的索引卡，你描述情绪/题材，它给出 2-3 个候选剧情，选定后直接输出可拍的四件套。

## 怎么用

### 安装

把 `screenwriter/` 文件夹复制到你的技能目录（如 `~/.claude/skills/screenwriter`、`~/.agents/skills/screenwriter`），或使用 Skills 安装机制引入本仓库。

### 使用示例

> "我想拍个 1 分钟的视频，最近心情治愈一点，想讲一个关于等待的故事。"

Skill 就会从索引卡片里匹配 2-3 个候选（附一句话梗概 + 推荐理由 + 高光片段），你选一个，它输出：

1. **剧情线**（钩子 → 发展 → 转折 → 收尾，60-90 秒）
2. **分镜表**（4-8 个镜头，每个镜头对应一张可拍/可找的照片）
3. **旁白文案**（口语化，可自己念或 TTS）
4. **标题与简介**（2-3 个标题备选）

## 四件套定义

- **剧情线**：钩子 → 发展 → 转折 → 收尾，60-90 秒讲完一个故事点。
- **分镜表**：4-8 个镜头，每镜含画面描述（对应一张照片）、镜头建议、预估时长。
- **旁白文案**：口语化，60-90 秒约 150-220 字，适合自己念或 TTS。
- **标题与简介**：2-3 个短视频标题备选 + 一段简介文案。
