# screenwriter 编剧 skill

> 想拍 1-2 分钟短视频，但没剧情、没灵感？这个技能从 **100 部中外文学名著**（70 部中国 + 30 部西方，全部公有领域）里为你匹配剧情，产出可直接开拍的剧本四件套。

## 它能做什么

- 你说出大致需求（**情绪 / 题材 / 时长 / 背景**，最多问 2-3 个问题）
- 它从 100 部名著索引卡中按「情绪标签 + 背景标签」匹配，给出 **2-3 个候选故事**（含推荐理由和高光片段）
- 你挑一个，它输出可直接用的：
  1. **剧情线** — 钩子 → 发展 → 转折 → 收尾（60-90 秒）
  2. **分镜表** — 每镜一句画面描述 + 镜头建议，对应你自己的照片
  3. **旁白文案** — 口语化，自己念或用 TTS
  4. **标题 / 简介** — 发布用

## 怎么用

对 DeepSeek Harness 说，例如：

> “我想拍个 1 分钟视频，想要治愈一点的，能拍我自己的生活场景”
> “来点热血悬疑的剧情，我要 2 分钟”

## 安装

**方式一：目录安装（推荐）**
把 `screenwriter` 文件夹放入技能目录：
- Windows：`C:\Users\<用户名>\.agents\skills\`
- 其他：`~/.agents/skills/`

**方式二：导入打包文件**
在 [Releases](../../releases) 下载 `screenwriter.skill`，按你使用的 Harness 导入。
